# 🕸️ Web Scraper with Python (BeautifulSoup)

This is a simple web scraping project developed using Python's `requests` and `BeautifulSoup` libraries. The scraper extracts article titles (specifically `<h2>` tag content) from any given URL.

---

## 🚀 Project Overview

This project was developed as part of my work at **Conifyz Technologies** to explore the fundamentals of web scraping, HTML parsing, and data extraction using Python.

---

## 🔧 Technologies Used

- **Python 3**
- **Requests** – for making HTTP requests
- **BeautifulSoup (bs4)** – for parsing HTML and extracting content

---

## 📁 How It Works

1. Takes a URL input from the user.
2. Sends a GET request to the URL.
3. Parses the HTML content using BeautifulSoup.
4. Extracts and prints all text within `<h2>` tags.
